# Повітряна тривога
Програма для увімкнення повітряної тривоги.

## Перед запуском
1. Підключіть до комп'ютера гучномовець чи інший пристрій для програвання аудіо
2. Забезпечте комп'ютер доступом до мережі Інтернет.

## Збірка
### Windows
1. Завантажте python 3.8 (вищі версії не підтримуються Windows 7) з сайту [python](https://www.python.org/downloads/release/python-3810/) і встановіть
2. Установіть git та 7-zip (з додавання до змінної оточення Path).
3. Установіть залежності (для цього потрібно відкрити термінал і ввести `pip install -r requirements.txt`)
4. З директорії репозиторія виконайте команду
```build.bat 0.0.0```
### Debian
1. З директорії репозиторія виконайте команду
```build.sh 0.0.0```


`0.0.0` - це бажана версія збірки.

## Функції
### Основні функції
* При повітряній тривозі сирена лунає 3 хвилини за замовчуванням (можна змінити)
* При закінченні повітряної тривоги лунає голосове сповіщення про її закінчення

### Додаткові функції
* О 9:00 лунає хвилина мовчання
* О 9:01 лунає лімн України
* Автозапуск програми при старті Операційної Системи
